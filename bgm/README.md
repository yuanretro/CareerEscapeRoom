# Background music

Put the music files in this folder, named `bgm1.mp3`, `bgm2.mp3`, `bgm3.mp3`, … with no gaps in the numbers.

They play in order, and after the last one the list starts again from `bgm1.mp3`. Music is on by default and starts after the player's first click or key press. The 🎵 button in the top bar turns it off.
